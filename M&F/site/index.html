۱. اتصال حساب Cloudflare

فقط توکن Cloudflare خودت را وارد کن؛ اتصال واسط توسط صاحب پروژه از قبل تنظیم شده است.
هنوز متصل نشده‌ای.

۲. منابع Cloudflare

اگر Namespace با همین نام از قبل وجود داشته باشد، دوباره ساخته نمی‌شود و همان مورد استفاده می‌شود.

۳. ورود مدیر

ADMIN_PASS فقط از API مربوط به Worker Secrets ثبت می‌شود؛ مقدار آن در Wrangler vars قرار نمی‌گیرد.

۴. کنترل جایگزینی Worker

فایل اصلی M&F/worker.js در این عملیات تغییر نمی‌کند.
