راه‌اندازی خودکار پنل M&F

ساخت یا استفادهٔ مجدد از KV، ساخت Worker از فایل worker.js، اتصال DB و تنظیم اطلاعات ورود و متغیرها.

۱. اتصال حساب Cloudflare

فقط توکن Cloudflare خودت را وارد کن؛ اتصال واسط توسط صاحب پروژه از قبل تنظیم شده است.
هنوز متصل نشده‌ای.

۲. منابع Cloudflare

اگر Namespace با همین نام از قبل وجود داشته باشد، دوباره ساخته نمی‌شود و همان مورد استفاده می‌شود. Binding در Worker دقیقاً DB خواهد بود.

۳. ورود مدیر

ADMIN_PASS فقط از API مربوط به Worker Secrets ثبت می‌شود؛ مقدار آن در Wrangler vars قرار نمی‌گیرد.

۴. کنترل جایگزینی Worker

فایل worker.js باید در پوشهٔ اصلی M&F کنار wrangler.jsonc باشد. تا وقتی فایل موجود نباشد، فقط مرحلهٔ ساخت/آماده‌سازی KV انجام می‌شود و هیچ کد آزمایشی روی Worker قرار نمی‌گیرد.
